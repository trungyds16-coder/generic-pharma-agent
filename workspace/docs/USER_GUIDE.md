# Hướng dẫn sử dụng

1. Chạy `python app.py` hoặc nhấn Play trên file `app.py` trong Local Agent.
2. Nhập phép tính như `(2 + 3) * 4` rồi nhấn **Tính**.
3. Nhập hàm theo biến `x`, chẳng hạn `sin(x) + x^2`; đặt khoảng và chọn **Vẽ đồ thị**.
4. Chọn **Tính tích phân** để tính diện tích có dấu bằng Simpson.
5. Chọn **Lưu SVG** để lưu đồ thị vector tại `docs/graph.svg`.

Ứng dụng không thực thi mã Python nhập vào. Biểu thức chỉ cho phép toán học và danh sách hàm đã nêu trong README.
